# Локализация AI Product Studio

## Обзор

AI Product Studio поддерживает полную локализацию интерфейса на два языка:
- **English** (английский) - по умолчанию
- **Русский** (русский)

## Как переключить язык

1. Откройте **Настройки** (Settings) в боковом меню
2. В разделе **Общие** (General) найдите пункт **Язык** (Language)
3. Выберите нужный язык из выпадающего списка:
   - English
   - Русский
4. Интерфейс немедленно переключится на выбранный язык
5. Выбор автоматически сохраняется и будет восстановлен при следующем запуске

## Техническая реализация

### Используемая библиотека
- **react-i18next** - стандарт де-факто для локализации React-приложений
- **i18next** - ядро системы локализации

### Структура файлов

```
src/
├── i18n/
│   ├── index.ts              # Конфигурация i18next
│   └── locales/
│       ├── en.json           # Английские переводы
│       └── ru.json           # Русские переводы
├── main.tsx                  # Инициализация i18n
└── components/               # Компоненты с useTranslation()
```

### Ключевые особенности

1. **Автоматическое сохранение выбора**
   - Язык сохраняется в localStorage
   - Ключ: `ai-studio-language`
   - Восстанавливается при каждом запуске

2. **Реактивное обновление**
   - Все компоненты используют хук `useTranslation()`
   - Интерфейс обновляется мгновенно при смене языка
   - Не требуется перезагрузка страницы

3. **Организация переводов**
   - Переводы сгруппированы по разделам:
     - `common` - общие элементы (кнопки, статусы)
     - `navigation` - навигация
     - `dashboard` - главная страница
     - `projects` - проекты
     - `settings` - настройки
     - `errors` - сообщения об ошибках
     - и другие...

4. **Интерполяция**
   - Поддержка переменных в переводах
   - Пример: `"projectCount": "{{count}} проект"`
   - Множественное число: `"projectCount_plural": "{{count}} проектов"`

### Использование в компонентах

```typescript
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation();
  
  return (
    <div>
      <h1>{t('dashboard.welcome')}</h1>
      <p>{t('projects.projectCount', { count: 5 })}</p>
    </div>
  );
}
```

## Что переводится

✅ **Переводится:**
- Все элементы интерфейса (кнопки, меню, заголовки)
- Сообщения об ошибках
- Подсказки (tooltips)
- Пустые состояния
- Статусы и индикаторы
- Диалоговые окна
- Настройки

❌ **Не переводится:**
- Названия AI-моделей (GPT-4, DALL-E 3 и т.д.)
- Названия провайдеров (OpenRouter)
- Технические идентификаторы
- Пользовательский контент (названия проектов, описания)
- Имена файлов
- API-ключи и секреты

## Добавление новых языков

Чтобы добавить новый язык:

1. Создайте файл перевода в `src/i18n/locales/`
   - Например: `de.json` для немецкого

2. Скопируйте структуру из `en.json` и переведите все строки

3. Обновите `src/i18n/index.ts`:
```typescript
import de from './locales/de.json';

i18n.init({
  resources: {
    en: { translation: en },
    ru: { translation: ru },
    de: { translation: de },  // Добавьте новый язык
  },
  // ...
});
```

4. Добавьте опцию в `src/pages/Settings.tsx`:
```typescript
<Select
  options={[
    { value: 'en', label: 'English' },
    { value: 'ru', label: 'Русский' },
    { value: 'de', label: 'Deutsch' }  // Добавьте новый язык
  ]}
  // ...
/>
```

## Рекомендации по переводу

### Для русского языка

Используйте естественные формулировки:
- ✅ "Создать проект" (не "Создание проекта")
- ✅ "Загрузить" (не "Аплоад")
- ✅ "Сгенерировать" (не "Генерировать")
- ✅ "Улучшить" (не "Импрув")

### Общие правила

1. **Краткость** - UI-элементы должны быть лаконичными
2. **Единообразие** - используйте одни и те же термины во всём приложении
3. **Контекст** - учитывайте контекст использования
4. **Длина** - проверяйте, что переводы помещаются в UI-элементы

## Тестирование

После изменения переводов:

1. Запустите приложение в режиме разработки:
   ```bash
   npm run dev
   ```

2. Переключите язык в настройках

3. Проверьте все разделы:
   - Dashboard
   - Projects
   - Library
   - Settings
   - Project View
   - Диалоговые окна
   - Сообщения об ошибках

4. Убедитесь, что:
   - Текст не обрезается
   - Нет hardcoded строк
   - Все элементы переведены
   - Множественное число работает корректно

## Известные ограничения

1. **Длина текста** - русский текст может быть длиннее английского на 10-30%
   - Решение: используйте `truncate` для длинных строк
   - Проверяйте UI на разных разрешениях

2. **Множественное число** - i18next автоматически обрабатывает множественное число
   - Используйте ключи с `_plural` для множественной формы
   - Пример: `projectCount` и `projectCount_plural`

3. **Динамический контент** - пользовательский контент не переводится
   - Это правильное поведение
   - Пользователи создают контент на своём языке

## Поддержка

Если вы нашли непереведённую строку:

1. Проверьте, что строка добавлена в `en.json` и `ru.json`
2. Убедитесь, что компонент использует `t()` вместо hardcoded строки
3. Проверьте консоль браузера на ошибки i18next
